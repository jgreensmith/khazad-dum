## Workflow 1.2.1 - Create Pre Experiment Questionnaire

## Objective
- Create a **Pre Experiment Questionnaire** using the provided **template**.
- Generate questions that are designed to clarify the parameters of the experiment.

## Requirements

 - **Review Experiment Plan**
- **Generate Questions**
- Generate between 2 and 8 questions that will are designed to obtained all the information required to determine: 
	- **Script requirements** - to be executed on experiment servers.
	- **Server Infrastructure requirements** - to deploy experiment servers.
- Challenging questions that encourage **written** answers are preferred, but you may provide guidance/ and other question types if necessary - please see the **template**
- Ask questions that address any ambiguities, undefined terms, or missing context.

#### Output Questionnaire File
The questionnaire should be saved as: `$CWD/documentation/02_experiment/process/pre-experiment-questionnaire.md`
