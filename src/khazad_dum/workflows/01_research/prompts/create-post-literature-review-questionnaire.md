## Post Literature Review Workflow

## Objective
- Create a **post literature review questionnaire** using the provided **template**.
- This workflow should help prepare the user and future agents for the experimental and architectural phase of the project.

## Requirements
#### Review 
- Review the following:
- **Project documentation** 
- **Pre-Literature review questionnaire**
- **Literature Review**

#### Generate Questions
- Generate between 4 and 12 questions that will help to create: 
	- **A Refined Project Description**
	- **Experiment Recommendations**
- Challenging questions that encourage manual research and **written** answers are preferred, but you may provide guidance/ and other question types if necessary - please see the **template**
- Ask questions that address any ambiguities, undefined terms, or missing context.

#### Output Questionnaire File
The questionnaire should be saved as: `$CWD/documentation/01_research/process/post-literature-review-questionnaire.md`
