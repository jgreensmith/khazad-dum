## Pre Literature Review Workflow
## Objective
- Create a **pre literature review questionnaire** using the provided **template** -based on the provided **Project Description**.

## Requirements
#### Review the Project Description
- The '**Project Overview**' section contains information about the overall project plan. actually building this project is out of scope for this workflow. 
- The '**Research Questions**' section contains specific questions that should be addressed in the literature review. 
- The '**Existing Technology**' section contains a list of technologies/ products that share similarities with the project. 

#### Generate Questions
- Generate between 3 and 12 questions that will help clarify the **Project Overview, Research Questions, and Existing Technologies** of the project. 
- Challenging questions that encourage manual research and **written** answers are preferred, but you may provide guidance/ and other question types if necessary - please see the **template**
- Ask questions that address any ambiguities, undefined terms, or missing context.

#### Output Questionnaire File
The questionnaire should be saved as: `$CWD/documentation/01_research/process/pre-literature-review-questionnaire.md`
